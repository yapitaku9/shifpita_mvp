# 機能一覧

このドキュメントは、アプリケーションが実装すべき機能を一覧化し、開発の優先順位を明確にするためのものです。

## 入力・設定機能 (Input & Settings)

| 機能ID   | 機能名                     | カテゴリ     | 優先順位 |
| :------- | :------------------------- | :----------- | :------- |
| `F-IN-01`  | 期間設定 (年月選択)        | 入力・設定   | 高       |
| `F-IN-02`  | 従業員リスト管理 (追加/削除) | 入力・設定   | 高       |
| `F-IN-03`  | 従業員役割設定             | 入力・設定   | 高       |
| `F-IN-04`  | 希望休設定                 | 入力・設定   | 高       |
| `F-IN-05`  | 特別日設定 (通院日)        | 入力・設定   | 中       |
| `F-IN-06`  | 基本ルール表示             | 入力・設定   | 低       |
| `F-IN-07`  | 基本ルール編集             | 入力・設定   | 低       |

## コア機能 (Core Engine)

| 機能ID   | 機能名                     | カテゴリ     | 優先順位 |
| :------- | :------------------------- | :----------- | :------- |
| `F-CO-01`  | シフト自動生成             | コア機能     | 高       |
| `F-CO-02`  | PDF出力                    | コア機能     | 高       |

---

### 優先順位の定義
- **高 (High):** MVPとして必須の機能。これがなければプロダクトとして成立しない。
- **中 (Medium):** MVPの価値をさらに高めるが、最初のリリースには必須ではない機能。
- **低 (Low):** 将来的な拡張機能。今回の開発スコープには含めない。
