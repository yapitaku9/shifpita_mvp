# 機能一覧

このドキュメントは、Webアプリケーションとして再設計されたShifPitaが実装すべき機能を一覧化するものです。

## 1. 共通・認証機能 (Common & Authentication)
| 機能ID | 機能名 | カテゴリ | 優先順位 | 備考 |
|---|---|---|---|---|
| F-CM-01 | ユーザーログイン | 認証 | 高 | |
| F-CM-02 | ユーザーログアウト | 認証 | 高 | |
| F-CM-03 | アクセス制御 | 認証 | 高 | 管理者/従業員の役割でアクセスできるページを制御 |
| F-CM-04 | メール通知 | 通知 | 中 | 希望休申請時、シフト作成完了時 |

## 2. 管理者機能 (Administrator)
| 機能ID | 機能名 | カテゴリ | 優先順位 | 備考 |
|---|---|---|---|---|
| F-AD-01 | 管理者ダッシュボード | 管理者 | 高 | 各機能へのエントリーポイント |
| F-AD-02 | 従業員アカウント管理 | 管理者 | 高 | CRUD操作（作成・一覧は実装済）|
| F-AD-03 | シフトルール管理 | 管理者 | 中 | 役割(雇用形態)、シフトパターン、固定ルールの管理 |
| F-AD-04 | シフト自動生成 | 管理者 | 高 | DBから情報を取得して実行 |
| F-AD-05 | シフト履歴確認 | 管理者 | 中 | (未実装) |
| F-AD-06 | PDFダウンロード | 管理者 | 中 | (DB連携は未実装) |

## 3. 従業員機能 (Employee)
| 機能ID | 機能名 | カテゴリ | 優先順位 | 備考 |
|---|---|---|---|---|
| F-EM-01 | 従業員ダッシュボード | 従業員 | 高 | |
| F-EM-02 | 希望休の申請・取消 | 従業員 | 高 | |
| F-EM-03 | 自身のシフト確認 | 従業員 | 高 | (未実装) |

---
### 優先順位の定義
- **高 (High):** アプリケーションの中核をなす必須機能。
- **中 (Medium):** アプリケーションの価値を高めるが、最低限の動作には必須ではない機能。
- **低 (Low):** 将来的な拡張機能。
