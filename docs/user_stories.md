# ShifPita MVP ユーザーストーリー

シフト作成者の視点から、本アプリケーションが提供すべき価値と、それを実現するための具体的な利用シナリオを記述します。

---

### 1. 今月のシフトを作成する準備をしたい

**ユーザーストーリー:**
シフト作成者として、私は**勤務する従業員をリストアップし、それぞれの役割（介護員、パート1など）を設定したい**。なぜなら、それによって従業員ごとの勤務ルール（夜勤の可否、月間勤務日数など）が自動的に適用されるからだ。

**受け入れ基準:**
- [ ] 勤務表を作成したい「年」と「月」を簡単に選択できる。
- [ ] 「従業員を追加」ボタンを押すと、新しい入力欄が表示される。
- [ ] 従業員の「名前」を入力できる。
- `介護員`, `パート1`, `パート2`, `パート3`, `パート4`, `責任者`, `サポート` の中から、従業員の「役割」をドロップダウンメニューで選択できる。
- [ ] 不要になった従業員をリストから削除できる。

### 2. 従業員の希望休と特別な勤務日を登録したい

**ユーザーストーリー:**
シフト作成者として、私は**各従業員の希望休をカレンダーで簡単に登録し、また、人員を増やす必要がある「通院日」を特別日として設定したい**。なぜなら、従業員の希望を確実に守り、日々の変動に柔軟に対応したシフトを作る必要があるからだ。

**受け入れ基準:**
- [ ] 従業員リストから名前を選ぶと、その月のカレンダーが表示される。
- [ ] カレンダーの日付をクリックするだけで、その従業員の「希望休」として登録・解除できる。
- [ ] 登録した希望休は、カレンダー上で誰の休みか視覚的にわかるように表示される。
- [ ] 月全体のカレンダーで、特定の日を「通院日」としてマークできる。
- [ ] 「通院日」としてマークした日に、何人追加で人員が必要か（例: 1人）を入力できる。

### 3. 施設の基本ルールを確認・調整したい

**ユーザーストーリー:**
シフト作成者として、私は**普段は固定されている施設の基本ルール（必要人数や連勤日数など）を確認し、必要に応じて一時的に調整したい**。なぜなら、予期せぬイベントなどで、稀に通常ルールを変更する必要があるからだ。

**受け入れ基準:**
- [ ] 「施設の基本ルール」を確認できる画面（またはアコーディオン形式のパネル）が存在する。
- [ ] 確認画面には、「最大連続勤務日数: 5日」「夜勤の翌日は明け休み」といった主要なルールが分かりやすく表示されている。
- [ ] 表示されているルールの一部（例: `介護員`の目標夜勤回数）は、数値を変更するなどの簡単な操作で編集できる。
- [ ] 編集したルールは、そのセッションでのシフト作成にのみ適用される。
- [ ] 変更したルールを、いつでも初期設定に戻せる「デフォルトに戻す」ボタンがある。

### 4. ワンクリックでルール通りの最適なシフトを生成したい

**ユーザーストーリー:**
シフト作成者として、私は**ボタンを一つ押すだけで、施設の全てのルール（ハード制約・ソフト制約）を考慮した勤務表を自動で作成してほしい**。なぜなら、複雑な条件をすべて手作業で確認するパズル作業から解放されたいからだ。

**受け入れ基準:**
- [ ] 画面に「シフトを自動作成する」ボタンが存在する。
- [ ] ボタンを押すと、計算中であることがわかるローディング表示がされる。
- [ ] **（ハード制約）** 生成された勤務表は、以下の条件を**絶対に**満たしている。
    - 日曜・平日ごとの必要人数
    - 通院日の追加人数
    - 最大連勤日数（5日）と特定の連続勤務上限（遅番/夜勤は4日）
    - 夜勤後の「明→休」ルール
    - 各役割に応じた月間勤務日数とシフト制限（パート2,3,4の夜勤不可）
    - 全員の希望休
- **（ソフト制約）** 生成された勤務表は、以下の目標を**可能な限り**達成しようと試みている。
    - 介護員の夜勤回数が10日に近い
    - 各パートの優先シフトが割り当てられている
    - 全員の連勤が短めになっている
    - 責任者とサポートが同日に勤務しない

### 5. 完成した勤務表を印刷・共有したい

**ユーザーストーリー:**
シフト作成者として、私は**自動生成された勤務表を、見やすいPDF形式でダウンロードしたい**。なぜなら、それを印刷して休憩室に掲示したり、関係者にメールで共有したりする必要があるからだ。

**受け入れ基準:**
- [ ] シフト作成が完了すると、「PDFをダウンロード」ボタンが表示される。
- [ ] ボタンをクリックすると、`勤務表_{年月}.pdf` のようなファイル名でPDFがダウンロードされる。
- [ ] PDFは、日付と従業員を軸にしたカレンダー形式で出力され、「早」「遅」「夜」「明」「休」といったシフトが一目でわかるようになっている。
- [ ] PDFの内容は、画面に表示されたプレビューと完全に一致する。
