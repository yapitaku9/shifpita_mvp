# ShifPita MVP ユーザーストーリー

本アプリケーションを利用する「管理者（シフト作成者）」と「従業員」の視点から、実現すべき価値と具体的な利用シナリオを記述します。

---

## 1. 管理者 (Administrator)

### 1.1. アプリケーションの利用を開始したい
**ユーザーストーリー:**
初めてアプリケーションをセットアップする管理者として、私は**自分自身の管理者アカウントを安全に作成したい**。なぜなら、これによって私だけが管理者機能を使えるようになるからだ。

**受け入れ基準:**
- [x] 初回アクセス時、または専用のコマンド実行によって、管理者アカウント作成プロセスが開始される。
- [x] ユーザーID（半角英数字6文字以上）とパスワード（半角数字4文字）を設定できる。
- [x] 作成後、他の人が管理者アカウントを追加できないようになっている。

### 1.2. 従業員を管理したい
**ユーザーストーリー:**
管理者として、私は**従業員のアカウント（ユーザーID、役割、メールアドレス等）を登録・管理したい**。なぜなら、シフト作成の対象となる人員を正確に把握し、シフト自動生成の基礎情報としたいからだ。

**受け入れ基準:**
- [x] 管理者ダッシュボードから、従業員の一覧を確認できる。
- [x] 新しい従業員のアカウントを、ユーザーID、役割、パスワードなどを設定して作成できる。
- [ ] 登録済みの従業員の情報を編集できる。（将来機能）
- [ ] 退職した従業員のアカウントを削除できる。（将来機能）

### 1.3. シフト作成のルールを管理したい
**ユーザーストーリー:**
管理者として、私は**施設の状況に合わせて、シフト計算の元となる各種ルールを柔軟に設定・変更したい**。なぜなら、ルール変更のたびに開発者に依頼することなく、現場で迅速に対応したいからだ。

**受け入れ基準:**
- [ ] 固定ルール（例: 最大連続勤務日数、時間帯ごとの必要人数）の一覧を確認し、数値を編集できる画面がある。
- [ ] 新しい「役割（雇用形態）」を追加したり、既存の役割の属性（例: 夜勤の可否）を編集したりできる。
- [ ] 新しい「シフトパターン（勤務時間）」を追加したり、既存のパターンを編集したりできる。
- [ ] 「この役割は、このシフトパターンでは働けない」といった、役割とシフトパターンの対応関係を編集できる。
- [ ] 設定したルールはデータベースに保存され、永続的に利用される。

### 1.4. シフトを自動作成し、共有したい
**ユーザーストーリー:**
管理者として、私は**全従業員から申請された希望休と、設定済みのルールを自動で考慮し、ワンクリックで最適なシフトを生成したい**。そして、**完成したシフトを従業員に通知し、PDFとしてダウンロードしたい**。なぜなら、シフト作成の負担をなくし、迅速な情報共有を実現したいからだ。

**受け入れ基準:**
- [x] 管理者ダッシュボードから、対象の年月を選択してシフト生成を開始できる。
- [x] 従業員が申請した希望休が、制約条件として自動的に読み込まれる。
- [x] 「シフト作成」ボタンを押すと、設定された全てのルールを考慮したシフトがバックエンドで計算される。
- [x] 作成が完了すると、シフトがデータベースに保存される。
- [x] シフト作成完了後、メールアドレスを登録している全従業員に通知メールが自動送信される。
- [ ] 完成したシフト表を、いつでもPDF形式でダウンロードできる。（DB連携は未実装）

## 2. 従業員 (Employee)

### 2.1. ログインして自分の情報を管理したい
**ユーザーストーリー:**
従業員として、私は**自分に割り当てられたアカウントでアプリケーションにログインしたい**。なぜなら、自分のシフト情報を確認したり、希望休を申請したりしたいからだ。

**受け入れ基準:**
- [x] ログインページから、自分のユーザーIDとパスワードでログインできる。
- [x] ログイン後、従業員専用のダッシュボードが表示される。
- [ ] 自分のパスワードやメールアドレスを変更できる。（将来機能）

### 2.2. 希望休を申請したい
**ユーザーストーリー:**
従業員として、私は**ダッシュボードから、希望する休みの日を簡単に申請・取り消ししたい**。なぜなら、電話や口頭ではなく、オンラインで確実に希望を伝えたいからだ。

**受け入れ基準:**
- [x] ダッシュボードに、希望休を申請するためのフォームが表示される。
- [x] 日付を選択して「申請」ボタンを押すと、希望休として登録される。
- [x] 申請が完了すると、管理者に通知メールが自動で送信される。
- [x] 申請済みの希望休の一覧が表示され、不要になった申請は取り消すことができる。

### 2.3. 自分のシフトを確認したい
**ユーザーストーリー:**
従業員として、私は**シフトが完成したら通知を受け取り、いつでもオンラインで自分の勤務スケジュールを確認したい**。なぜなら、掲示板を見に行かなくても、手元のスマートフォンやPCでシフトを把握したいからだ。

**受け入れ基準:**
- [x] シフトが完成すると、登録したメールアドレスに通知が届く。
- [ ] ログイン後のダッシュボードで、自分の割り当てられたシフトがカレンダー形式などで分かりやすく表示される。（未実装）
