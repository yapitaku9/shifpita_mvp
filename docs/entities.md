# エンティティ一覧

本アプリケーションにおけるデータの実体（エンティティ）を定義します。
なお、本MVPは「データ保存機能は範囲外」であるため、これらのエンティティは主にメモリ上のオブジェクトやJSONデータ構造として扱われます。

## 1. マスタデータ (Master Data)

システム内部で定数や設定として保持される、変更頻度の低い定義データです。

| エンティティ名 | 物理名 (例) | 種類 | 主キー | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| **役割** | `Role` | Master | `role_id` | 従業員の職種や役割（介護員, パート1など）。夜勤可否や勤務日数規定などの属性を持つ。 |
| **シフト区分** | `ShiftType` | Master | `shift_type_id` | 勤務の種類（早1, 遅1, 夜1, 休など）。開始・終了時刻を持つ。 |
| **制約ルール** | `ConstraintRule` | Master | `rule_id` | シフト作成時のルール定義（ハード制約・ソフト制約）。必要人数や連続勤務上限など。 |

## 2. トランザクションデータ (Transaction Data)

ユーザーが利用の都度入力するデータ、および計算結果として生成されるデータです。

| エンティティ名 | 物理名 (例) | 種類 | 主キー | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| **シフト作成コンテキスト** | `ShiftContext` | Transaction | `(なし)` | 今回作成するシフトの基本設定（対象年、対象月）。 |
| **従業員** | `Employee` | Transaction | `employee_id` | その月に勤務するスタッフの情報。役割IDを持つ。 |
| **希望休** | `DayOffRequest` | Transaction | `request_id` | 従業員ごとの希望休情報。従業員と日付を紐付ける。 |
| **特別日** | `SpecialDay` | Transaction | `date` | 通院日など、通常と異なる人員配置が必要な日とその追加人数。 |
| **シフト割当結果** | `ShiftAssignment` | Transaction | `assignment_id` | 自動生成されたシフト表の中身。日付、従業員、シフト区分の組み合わせ。 |
