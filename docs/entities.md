# エンティティ一覧

本アプリケーションにおける主要なデータエンティティ（データベースモデル）を定義します。

---

## 1. マスタデータ (Master Data)

アプリケーションの動作の前提となる、比較的変更頻度の低いデータです。

| エンティティ名 | 物理名 (例) | 説明 |
| :--- | :--- | :--- |
| **役割** | `Role` | 従業員の役割（例: `管理者`, `介護員`, `パート1`）。ユーザーに紐付き、アクセス権限やシフト生成時の制約条件として利用される。 |
| **シフトパターン** | `ShiftType` | 勤務の種類（例: `早1`, `夜1`, `休`）。名称、開始時刻、終了時刻などの属性を持つ。 |
| **マスター設定**| `Master` | アプリケーション全体の動作を定義する設定値（例: `連続勤務上限`, `夜勤後の必須休日`）。 |


---

## 2. トランザクションデータ (Transaction Data)

ユーザーの操作によって日々生成・更新されるデータです。

| エンティティ名 | 物理名 (例) | 説明 |
| :--- | :--- | :--- |
| **ユーザー** | `User` | アプリケーションの全利用者。ログインID、パスワードハッシュ、メールアドレスを持ち、**役割(Role)** に関連付けられる。従業員と管理者の両方を含む。 |
| **希望休申請** | `DayOffRequest` | **ユーザー**が特定の日付の休みを申請した記録。 |
| **シフト生成履歴** | `Transaction` | 管理者がシフト自動生成を実行した履歴。対象年月や生成日時、成功/失敗のステータスを記録する。 |
| **シフト** | `Shift` | 生成されたシフトの各コマ。どの**ユーザー**が、どの日付に、どの**シフトパターン**で勤務するかを記録し、特定の**シフト生成履歴**に関連付けられる。 |
